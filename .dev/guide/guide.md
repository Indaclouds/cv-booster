---
title: "CV Booster : guide d'utilisation"
---

CV Booster vous aide à construire votre CV à partir de vos documents, à le relire, à l'adapter à une offre
d'emploi et à le mettre en page. L'assistant ne modifie **rien sans votre accord**.

# 1. Installer (une seule fois, quelques minutes)

1. Double-cliquez sur **Installer CV Booster**.
2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**,
   puis **Exécuter quand même**. C'est normal pour un fichier téléchargé.
3. Cliquez sur **Installer**, laissez faire, puis **Terminer** : CV Booster s'ouvre.
4. Au premier lancement, l'Accueil vous propose **Se connecter** : une page s'ouvre dans votre navigateur,
   **connectez-vous avec votre compte Claude** (forfait Pro), puis revenez dans CV Booster. C'est tout.

Vous retrouvez ensuite **CV Booster** dans le menu Démarrer et sur votre Bureau. Vos documents et vos CV
sont rangés dans **Documents › CV Booster**.

# 2. Pour démarrer (une seule fois)

L'**Accueil** coche les étapes au fur et à mesure et montre toujours ce qu'il reste à faire.

1. **Mes documents › Mes infos** : déposez votre dernier CV (Word ou PDF), l'**export PDF de votre profil
   LinkedIn** (sur votre profil : *Plus › Enregistrer au format PDF*), vos notes, votre photo. Un texte
   **barré** dans un document est considéré comme écarté.
2. Facultatif, **Mes documents › Designs** : jusqu'à 3 CV dont le design vous plaît (image ou PDF). Chacun est
   reproduit fidèlement, rempli avec votre CV : vous choisissez ensuite celui que vous préférez.
3. **Créer mon CV** (Accueil) : CV Booster lit vos documents, en tire un CV avec vos propres mots, reproduit vos
   designs et prépare le PDF. Comptez quelques minutes : vous pouvez faire autre chose, vous serez prévenu.

# 3. Mon CV : l'assistant à gauche, votre CV à droite

À droite, votre CV est **toujours à jour** : son PDF se refait tout seul après chaque modification. Choisissez
la **Version** (une par type de poste ou par offre) et, si vous en avez plusieurs, le **Design**. Cliquez sur
l'aperçu pour l'ouvrir en grand. Le menu « … » à côté de la version : nouvelle version, versions précédentes,
dossier des PDF, supprimer la version.

À gauche, choisissez ce que vous voulez faire :

- **Corriger les fautes** : orthographe, typographie, cohérence.
- **Retoucher une partie** : l'accroche, une expérience, les compétences ; dites ce que vous voulez si vous le
  savez (« plus court », « mettre en avant le management »).
- **Adapter à une offre** : collez l'annonce ; une version sur mesure est créée, sans toucher aux autres. Avant,
  **Vérifier la correspondance** (gratuit) montre les mots-clés de l'annonce déjà présents et ceux qui manquent.
- **Nouvelle version** : une version pour un autre type de poste, sans annonce.
- **Changer le design** : vos CV d'exemple reproduits fidèlement, ou, sans exemple, le style que vous décrivez.
- **Version anglaise** : la version affichée, traduite par un professionnel du recrutement.
- **Ce que cherchent les recruteurs** : compétences, outils et salaires de votre métier, avec les sources.
- **Écrire une lettre de motivation** : collez l'annonce ; la lettre, dans le design de votre CV, apparaît sous
  votre CV.
- **Préparer un entretien** : les questions probables, des pistes de réponse, et un entraînement si vous voulez.

L'assistant propose, **vous décidez** :

- quand il propose des corrections, **cochez** celles que vous voulez, puis **Tout appliquer** (ou
  *Appliquer la sélection*), ou **Ne rien changer** ;
- un bandeau vert dit ce qui a été modifié : **Voir les changements**, et **Annuler** pour revenir en arrière ;
- quand c'est fini, **Faire autre chose** ; vos conversations restent dans *Vos dernières demandes*.

Votre CV dépasse une page avec un design ? Sous l'aperçu, choisissez : **Raccourcir mon CV**, **Design plus
compact** ou **Garder 2 pages**.

# 4. Trois fichiers : lequel envoyer ?

| Bouton | À utiliser pour |
|---|---|
| **CV** | un recruteur : e-mail, impression, entretien |
| **CV - ATS** (une colonne, sans décoration) | les sites d'emploi et formulaires en ligne |
| **Format Word** | quand un cabinet ou un recruteur vous le demande |

Un **ATS** est un logiciel qui trie les candidatures avant qu'un humain ne les lise. Il lit mal les colonnes
et les icônes : le CV - ATS est fait pour lui.

**Candidatures** : notez où vous avez postulé et avec quelle version. Chaque ligne propose la suite
(*C'est envoyé*, *Préparer une relance*, *J'ai un entretien*) ; sans nouvelles après 10 jours, la ligne vous le
signale, et l'Accueil vous le rappelle dans *À faire*.

# 5. Bon à savoir

- **Votre forfait Claude est limité.** Chaque action affiche sa durée ; une longue conversation coûte plus
  cher : passez à *Faire autre chose* entre deux sujets. La recherche sur les recruteurs réutilise sa fiche
  pendant 3 mois.
- **Puissance** (menu de gauche) : **Moyen** la plupart du temps ; **Faible** quand votre forfait est presque
  épuisé (environ 9 fois moins pour une relecture) ; **Fort** pour une candidature importante (bien plus
  gourmand : revenez sur Moyen ensuite). Le changement vaut dès la demande suivante.
- **Relisez toujours votre CV à voix haute** : ce qui ne sonne pas comme vous, enlevez-le.
- **Vos fichiers** : vos PDF sont dans **CV**, vos documents dans **ressources**. Le reste est caché, ne
  le supprimez pas.
- **Sauvegarde** (menu de gauche) : *Sauvegarder mes données* range tout dans un seul fichier (clé USB,
  cloud). Sur un nouvel ordinateur : installez CV Booster, puis *Restaurer une sauvegarde*.
- **Coulisses** (en bas à gauche) : pour comprendre comment marchent les agents et les Skills, voir votre
  consommation, et **créer votre propre agent**, que vous lancez ensuite depuis *Mon CV › Mes agents*.
- **Mises à jour** : quand une nouvelle version existe, l'Accueil vous la propose. Un clic : CV Booster se
  ferme, se met à jour et se rouvre. Vos documents, vos CV et vos agents modifiés ne bougent pas.

# 6. En cas de souci

| Ce qui se passe | Que faire |
|---|---|
| Quelque chose ne marche pas | En bas de l'Accueil : **Signaler un problème**. Un fichier apparaît sur votre Bureau : envoyez-le à la personne qui vous a installé CV Booster (il ne contient ni votre CV ni vos documents). |
| Un message dit qu'il manque un composant | Vérifiez votre connexion Internet et relancez **Installer CV Booster**. Si ça recommence, envoyez le fichier **journal-installation.txt** (dans Documents › CV Booster). |
| « Claude n'est pas connecté » | Cliquez sur **Me connecter à Claude**, connectez-vous dans la page qui s'ouvre, puis réessayez. Si la page affiche un code, collez-le dans CV Booster. |
| « Limite d'utilisation atteinte » | Votre forfait se recharge au bout de quelques heures : réessayez plus tard. |
| Le CV fait plus d'une page | Sous l'aperçu de *Mon CV* : **Raccourcir mon CV**, **Design plus compact** ou **Garder 2 pages**. |
| Désinstaller | Paramètres Windows › **Applications installées** › CV Booster › Désinstaller. Vos documents et vos CV sont conservés. |
| La fenêtre ne répond plus | Clic droit sur la barre des tâches › **Gestionnaire des tâches**, sélectionnez CV Booster › **Fin de tâche**, puis relancez. Vos fichiers ne sont pas perdus. |
