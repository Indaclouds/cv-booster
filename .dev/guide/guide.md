---
title: "CV Booster : guide d'utilisation"
---

CV Booster vous aide à construire votre CV à partir de vos documents, à le relire, à l'adapter à une offre
d'emploi et à le mettre en page. L'assistant ne modifie **rien sans votre accord**.

# 1. Installer (une seule fois, quelques minutes)

1. Double-cliquez sur **Installer CV Booster**.
2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**,
   puis **Exécuter quand même**. C'est normal pour un fichier téléchargé.
3. Cliquez sur **Installer**, laissez faire, puis **Terminer** : CV Booster s'ouvre.
4. Au premier lancement, l'Accueil vous propose **Se connecter** : une page s'ouvre dans votre navigateur,
   **connectez-vous avec votre compte Claude** (forfait Pro), puis revenez dans CV Booster. C'est tout.

Vous retrouvez ensuite **CV Booster** dans le menu Démarrer et sur votre Bureau. Vos documents et vos CV
sont rangés dans **Documents › CV Booster**.

# 2. Le parcours, étape par étape

L'**Accueil** vous indique toujours la **prochaine étape** : suivez-la, vous ne pouvez pas vous tromper.

1. **Mes documents › Mes infos** : déposez votre ancien CV, vos notes, votre photo (glissez les fichiers
   dans la liste). Un texte **barré** dans un document est considéré comme écarté.
2. **Créer mon CV** : CV Booster lit vos documents et en tire un CV structuré, avec vos propres mots.
3. **Améliorer** : choisissez un onglet.
   - **Relire** : fautes, typographie, cohérence.
   - **Reformuler** : des phrases plus percutantes, une partie à la fois.
   - **Adapter à une offre** : collez l'annonce ; une version sur mesure est créée, sans toucher aux autres.
   - **Veille marché** : ce que les recruteurs demandent pour votre métier, avec les sources.
   - **Design** : reproduit le style d'un CV qui vous plaît (déposez-le dans *Mes documents › Exemples de
     design*).
   - **Lettre** : collez l'annonce ; une lettre courte, appuyée sur vos vraies expériences. Son PDF arrive
     dans *Mes CV*, avec votre police et votre couleur.
   - **Entretien** : les questions probables, des pistes de réponse tirées de votre parcours, et un
     entraînement question par question si vous voulez.
   - **Anglais** : une traduction professionnelle de toutes vos versions ; elles apparaissent ensuite dans
     *Mes CV*, avec un petit drapeau.

   Avant d'adapter votre CV à une offre, cliquez sur **Vérifier la correspondance** (gratuit) : vous voyez
   quels mots-clés de l'annonce sont déjà dans votre CV, et lesquels manquent.

   L'assistant propose, **vous décidez** : répondez par exemple « tout appliquer », « seulement 1 et 3 »
   ou « non pour le 2 ». Cliquez sur **Terminer** quand c'est fini.
4. **Mes CV** : choisissez la version, cliquez sur **Générer le PDF**. L'aperçu s'affiche à droite.
   Une modification ne vous plaît pas ? **Versions précédentes** : votre CV est mis de côté avant chaque
   passage de l'assistant, vous pouvez y revenir.
   Un cabinet demande un fichier Word ? Menu à trois points d'une version › **Exporter en Word**.
5. **Candidatures** : notez où vous avez postulé et avec quelle version. Les onglets trient par étape, et
   chaque ligne propose la suite : **C'est envoyé**, **Préparer une relance** (un court e-mail prêt à
   copier), **J'ai un entretien**, **Préparer l'entretien**. Sans nouvelles après 10 jours, la ligne vous
   le signale.

# 3. Deux PDF : lequel envoyer ?

Chaque version de votre CV donne deux fichiers dans le dossier **CV** :

| Fichier | À utiliser pour |
|---|---|
| **Avec design** | un recruteur : e-mail, impression, entretien |
| **ATS** (une colonne, sans décoration) | les sites d'emploi et formulaires en ligne |

Un **ATS** est un logiciel qui trie les candidatures avant qu'un humain ne les lise. Il lit mal les colonnes
et les icônes : la version ATS est faite pour lui.

# 4. Bon à savoir

- **Votre forfait Claude est limité.** Cliquez sur **Terminer** entre deux tâches : une longue
  conversation coûte plus cher. La veille marché réutilise sa fiche pendant 3 mois.
- **Relisez toujours votre CV à voix haute** : ce qui ne sonne pas comme vous, enlevez-le.
- **Vos fichiers** : vos PDF sont dans **CV**, vos documents dans **ressources**. Le reste est caché, ne
  le supprimez pas.
- **Coulisses** (en bas à gauche) : pour comprendre comment marchent les agents et les Skills, vous
  entraîner à les modifier, et **créer votre propre agent** (bouton *Créer un agent*), que vous lancez
  ensuite depuis *Améliorer › Mes agents*.
- **Sauvegarde** : *Mes documents › Sauvegarder mes données* range tout dans un seul fichier (clé USB,
  cloud). Sur un nouvel ordinateur : installez CV Booster, puis *Restaurer une sauvegarde*.
- **Votre consommation** (dans *Coulisses*) : ce que chaque action utilise de votre forfait.
- **Puissance** (en haut d'*Améliorer*) : **Moyen** la plupart du temps ; **Faible** quand votre forfait
  est presque épuisé (environ 9 fois moins pour une relecture) ; **Fort** pour une candidature importante
  (bien plus gourmand : revenez sur Moyen ensuite).
- **Mises à jour** : quand une nouvelle version existe, l'Accueil vous la propose. Un clic : CV Booster se
  ferme, se met à jour et se rouvre. Vos documents, vos CV et vos agents modifiés ne bougent pas.

# 5. En cas de souci

| Ce qui se passe | Que faire |
|---|---|
| Quelque chose ne marche pas | En bas de l'Accueil : **Signaler un problème**. Un fichier apparaît sur votre Bureau : envoyez-le à la personne qui vous a installé CV Booster (il ne contient ni votre CV ni vos documents). |
| Un message dit qu'il manque un composant | Vérifiez votre connexion Internet et relancez **Installer CV Booster**. Si ça recommence, envoyez le fichier **journal-installation.txt** (dans Documents › CV Booster). |
| « Claude n'est pas connecté » | Cliquez sur **Me connecter à Claude**, connectez-vous dans la page qui s'ouvre, puis réessayez. Si la page affiche un code, collez-le dans CV Booster. |
| « Limite d'utilisation atteinte » | Votre forfait se recharge au bout de quelques heures : réessayez plus tard. |
| Le PDF fait plus d'une page | Utilisez **Reformuler** pour raccourcir. |
| Désinstaller | Paramètres Windows › **Applications installées** › CV Booster › Désinstaller. Vos documents et vos CV sont conservés. |
| La fenêtre ne répond plus | Clic droit sur la barre des tâches › **Gestionnaire des tâches**, sélectionnez CV Booster › **Fin de tâche**, puis relancez. Vos fichiers ne sont pas perdus. |
